# ECHO: Последний сигнал — 2D AI-голосовой квест

**Версия:** 0.1.0 (первый игровой прототип / vertical slice)  
**Дисциплина:** Управление IT-проектами  
**Платформа:** Windows 10/11, Python 3.11–3.12 рекомендуется  
**Технологии:** Python · Pygame-ce · Vosk (настоящий офлайн AI/STT) · sounddevice · SQLite

## 1. Как запустить на Windows

1. Распакуйте ZIP целиком, например в `C:\Projects\ECHO_Last_Signal`.
2. Установите **Python 3.11 или 3.12**, если он ещё не установлен. На установщике отметьте «Add python.exe to PATH».
3. Дважды нажмите **`01_SETUP.bat`**. Скрипт создаст `.venv` и поставит библиотеки из `requirements.txt`. Нужен интернет **только для установки**.
4. Дважды нажмите **`02_RUN.bat`**. Откроется меню игры. **Уже сейчас** можно пройти первый уровень, используя WASD и клавиши 1–8 / E.
5. Чтобы заработал настоящий голосовой AI, один раз запустите **`03_DOWNLOAD_VOICE_MODEL.bat`**. Он скачает русскую модель Vosk (примерно 45 МБ ZIP) с официального сайта. Затем перезапустите игру и нажмите **F8**, если микрофон не включился сам.

> Голосовая модель **не входит** в маленький ZIP проекта. Пока модель не загружена, на панели честно отображается «НЕТ МОДЕЛИ», а клавиатурные команды дают протестировать всю игру. Игровой процесс не имитирует работу нейросети: настоящий голос обрабатывает установленная Vosk.

Если Windows запретит доступ к микрофону: **Параметры → Конфиденциальность и безопасность → Микрофон → Разрешить классическим приложениям доступ к микрофону**. Убедитесь, что микрофон выбран устройством ввода по умолчанию.

## 2. Запуск через PyCharm

1. PyCharm → **Open** → выбрать распакованную папку `ECHO_Last_Signal`.
2. В терминале PyCharm:

   ```powershell
   py -3.12 -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   .\.venv\Scripts\python.exe download_voice_model.py
   .\.venv\Scripts\python.exe main.py
   ```

   Вместо `py -3.12` можно использовать установленный `py -3.11`.
3. В **Settings → Project → Python Interpreter** выберите `.venv\Scripts\python.exe`, чтобы PyCharm использовал нужные библиотеки.
4. **Run → Edit Configurations → Python → Script path:** `main.py`; **Working directory:** корень `ECHO_Last_Signal`.

## 3. Управление

| Действие | Голос (русский) | Клавиатура для проверки |
|---|---|---|
| Движение | — | WASD / стрелки |
| Контекстное действие рядом | — | E |
| Сканировать терминал | «Сканируй» | 1 |
| Взломать терминал | «Взломай» | 2 |
| Открыть шлюз | «Открой» | 3 |
| Защитное поле на 4 секунды | «Щит» | 4 |
| Активировать ядро | «Активируй» | 5 |
| Получить подсказку Новы | «Помощь» | 6 |
| Спросить состояние здоровья/энергии | «Статус» | 7 |
| Оглушить дрона на 5 секунд | «Импульс» | 8 |
| Включить / выключить микрофон | — | F8 |
| Справка | — | H или F1 |
| Пауза | — | P или Esc |

**Произносите команды отдельно, с небольшой паузой после фразы**. В распознавании используется ограниченная грамматика из известных слов и нескольких вариантов каждой команды. При одновременном вводе WASD и голосовые действия совместимы.

## 4. Как пройти первый уровень

- Найдите голубой **терминал** в левой верхней половине станции. Подойдите и скажите «Сканируй» (или нажмите `1`).
- Не отходя, скажите «Взломай» (`2`).
- Подойдите к центральному шлюзу, который разделяет станцию пополам, и скажите «Открой» (`3`).
- Избегая красного охранного дрона, пройдите к **ядру** в правом верхнем секторе и скажите «Активируй» (`5`).
- Доберитесь до **аварийного выхода** в правом нижнем секторе — это победа.

**Дополнительные механики:** красный лазерный пол на левой стороне, охранный дрон, временный щит, электроимпульс, энергокапсула и подсказки. Ошибки влияют на скорость дрона и цикл лазера. Состояние здоровье/энергия/очки/цель отображается в интерфейсе.

**Поражение:** если здоровье падает до нуля. **Победа:** восстановление ядра и достижение аварийного выхода.

## 5. Какая здесь нейросеть и что делает адаптивность

**AI №1 — Vosk**: использует настоящую предварительно обученную модель машинного обучения для распознавания русской речи **офлайн**. Поток: `микрофон → модель Vosk → распознанный текст → commands.interpret → world.command → действие внутри игры`. Без распознанного слова команда не будет выдана; клавиатура — отдельный, явно обозначенный тестовый ввод.

**Интеллектуальная механика №2 — адаптивная сложность**: алгоритм на правилах (не нейросеть). Он анализирует количество неверных действий, успешные действия и здоровье персонажа. При серии ошибок снижает скорость дрона и частоту срабатывания лазера; при успешной игре без ошибок повышает сложность. Это можно продемонстрировать на защите, объяснив правила в `echo_game/world.py` (свойство `difficulty`).

## 6. Результаты

После победы или поражения программа автоматически записывает попытку в `save/echo_progress.db` (SQLite). Доступны попытки, победы, рекорд и список последних пяти забегов через кнопку **«Статистика»** в главном меню. СУБД/сервер устанавливать не нужно.

## 8. Тестирование

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

19 тестов проверяют логику команд, условия победы, столкновения, этапы миссии, ресурсы, ошибочные действия, адаптацию и SQLite.

**Отдельное экспериментальное тестирование распознавания речи** (акцент, шум, точность 8 команд) ещё предстоит выполнить на реальном микрофоне. Автоматические тесты не являются доказательством измеренной точности AI.

## 9. Что ещё не реализовано в версии 0.1

Это **первый играбельный уровень, а не вся финальная игра**. Для полного соответствия заданию лабораторных 8–15 в следующих версиях понадобятся:

- уровни 2 и 3 с цепочками команд и сюжетными развилками;
- больше испытаний, финальный дизайн, музыка/звуки, дополнительные анимации;
- экран магазина и **учебный** механизм тестовой покупки Premium-дополнения;
- полное функциональное тестирование, AI-эксперименты с реальными людьми и документация;
- GitHub-репозиторий с реальными коммитами обоих студентов.

Сейчас уже есть два самостоятельно нарисованных персонажа (Алекс и Нова), охранный дрон, цель, ресурсы, победа/поражение, сохранения, базовый AI и адаптивная сложность.

## 10. Источники зависимостей

- Официальные модели Vosk: https://alphacephei.com/vosk/models
- Pygame-ce: https://pyga.me/
- Vosk API: https://github.com/alphacep/vosk-api

Языковая модель Vosk распространяется независимо от проекта согласно лицензии, указанной её авторами (в списке моделей: Apache 2.0). Библиотечные и модельные веса не включены в ZIP.
