# ECHO: Последний сигнал — Editable Final Release v2.1

2D Sci-Fi Stealth / AI Voice Quest по теме №9 «AI-голосовой квест» (дисциплина «Управление IT-проектами»). Это **исходный проект** Python/Pygame-ce, а не видео или скриншот. Версия 2.1 получила полный cinematic top-down редизайн: объёмные стены, многослойные металлические палубы, встроенный декор, практический свет, мягкие тени, новый компактный HUD и тактическую мини-карту. Боевые действия сопровождаются отдельными анимациями турели, дрона и EMP-импульса, а туман войны показывает узкий безопасный предпросмотр за открытым проходом. Сохранены 3 сектора, 9 логических терминалов, Vosk, Q-learning, камеры/турели/дроны, комнаты, заметки, навыки Новы и сохранения.

## Запуск на Windows 11

1. Распакуй архив в `C:\Games\ECHO` (не запускай из ZIP).
2. Установи Python **3.11 или 3.12**, при установке отметь `Add to PATH`.
3. Запусти `01_SETUP.bat` (установит pygame-ce и прочие требования из `requirements-game.txt`; нужен интернет).
4. Запусти `02_RUN.bat` или `main.py` через виртуальное окружение `.venv`.
5. Для голосового AI (обязательно для защиты) запусти `03_DOWNLOAD_VOICE_MODEL.bat`. Он устанавливает vosk и скачивает официальную русскоязычную модель (~45 МБ). Затем запусти игру, нажми **V** и проверь микрофон. **Модель не включена в архив**, поскольку её необходимо скачать отдельно.
6. Проверка кода: `04_TEST.bat`. Дополнительный запуск: `.venv\Scripts\python.exe -m unittest discover -s tests -v`.

**Если игра не открылась:** посмотри текст консоли и `crash_log.txt`. Если fullscreen работает некорректно, открой `assets/ui/theme.json`, измени `"fullscreen": false` и запусти снова. Внутри можно переключить F11.

## Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки | Передвижение |
| Shift | Бег — создаёт шум |
| E / Space | Поднять предмет, получить запись, открыть логический терминал |
| 1–3 | Выбрать ответ, когда логический терминал открыт |
| Tab | Панель команд Новы |
| 1–0 / - / = / Backspace | Резервная проверка голосовых команд, когда пазл закрыт |
| V | Включить/выключить настоящий Vosk-модуль |
| N | Заметки и инженерные схемы |
| M | Карта текущей комнаты |
| H / B / G | Аптечка / батарея / отвлекающий маяк |
| Esc | Назад / пауза |
| F11 | Fullscreen / оконный |

### Маршрут прохождения каждого уровня

1. Исследуй комнаты, найди два логических терминала **A/B** (значок «ЗАГАДКА»), ответь на вопросы: открываются клавишей **E**, ответы **1–3** или мышью. Ответы сохраняются.
2. Найди модули сканирования и взлома и карту доступа; у главного терминала произнеси **«Подключение → Сканируй → Взломай → Открой»**. Шлюз A откроется после двух задач.
3. Перейди во второй сектор, реши третий логический терминал **C**.
4. Подойди к ядру: справа показывается **постоянная инженерная схема**: цветовые функции и нужные действия. Она также сохраняется в заметках **N**. Произнеси **«Сканируй → Отключи [цвет] → Активируй [цвет] → Открой»**.
5. Шлюз B откроется, доберись до выхода, нажми **E**. Пройди все три уровня и выбери концовку.

При ошибке логического терминала тревога увеличивается, но можно попробовать снова. Игрок перемещается самостоятельно, Нова получает новые способности только после нахождения модулей.

## Интеллектуальные компоненты

- **AI №1 (локальная ML-модель):** Vosk распознаёт русскую речь, словарь и обработка команд в `echo_game/voice.py` + `commands.py`. Реальную точность нужно проверить микрофоном.
- **AI №2 (локальный RL-алгоритм):** `echo_game/adaptive.py` — табличный Q-learning. Переход между комнатами запускает оценку статистики и выбор следующей сложности. Таблица сохраняется в `save_data/adaptive_qtable.json`. Это обучаемый агент, не LLM и не нейросеть.
- **Security AI:** патруль/поиск/преследование дронов и проверка видимости за стенами, в `world.py`.

## Структура редактируемых материалов

- `maps/level_1.tmj` ... `level_3.tmj` — карты Tiled. В объектных слоях лежат «puzzle» с `puzzle_id`.
- `story/puzzles.json` — 9 интерактивных задач, варианты ответа, объяснение, награды. Можно редактировать текст и число правильного ответа (индекс 0–2).
- `story/levels.json` — диалоги, названия сектора, подсказки, описание событий.
- `assets/source_svg/*.svg` — редактируемая векторная графика Inkscape, включая puzzle.svg.
- `assets/sprites/*.png` — экспорт SVG в игровые спрайты; после изменения SVG запусти `scripts/export_svg.py` (нужен CairoSVG).
- `assets/ui/theme.json` — параметры экрана, палитра и звук.
- `assets/ui/design_reference.png` — художественный концепт выбранного направления; **это не спрайт и не игра**.
- `assets/ui/menu_backdrop.png` — производный мягкий фон меню из концепта.
- `docs/V2_1_VISUAL_SYSTEM.md` — карта нового визуального слоя и инструкция по безопасному редактированию.
- `assets/audio/*.wav` — оригинальные редактируемые эффекты, `assets/audio/*.ogg` — новые музыкальные темы и слои. У каждой камеры, дрона, турели и головоломки есть свой звук; настройки музыки и эффектов раздельны. Подробнее: `docs/AUDIO_V2_1_1.md`.
- `save_data/` — прогресс SQLite и обучающаяся таблица.
- `docs/labs_08_15/` — отдельные документы по каждой из 8 лабораторных.

**Внимание:** `scripts/create_content.py` — исходный генератор карт v1, его запуск **перезапишет** Tiled-файлы и потеряет добавленные головоломки. Для изменения существующих уровней используй Tiled.

## Реально проверено и что осталось

Логика проверена автоматическими unit tests в среде сборки. Запуск окна Pygame, реальный микрофон Vosk, FPS на Windows и полное ручное прохождение всех вариантов **не подтверждены в среде сборки**. Для окончательной сдачи также требуются реальные коммиты двух участников и тестирование 3 внешними пользователями согласно методичке. Подготовленные документы не заменяют этих действий.

## Лицензии/источники

Оригинальные игровые спрайты в SVG, карты TMJ, сюжет и интерфейс. Референс-концепт сгенерирован для этого проекта. Vosk — сторонняя библиотека/модель, загружается отдельно. Аудио в текущей сборке — синтетические игровые эффекты, не скачанные коммерческие записи. Магазин — демонстрация без реальной оплаты.
