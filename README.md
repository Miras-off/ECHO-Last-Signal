# ECHO: Последний сигнал

**Версия 1.0 • 2D Sci‑Fi Stealth / Voice Quest**  
Оригинальная учебная игра по теме №9 «AI-голосовой квест» (Управление IT-проектами).

## Быстрый запуск на Windows

1. Распакуй ZIP в папку без русских/сложных спецсимволов, например `C:\Games\ECHO`.
2. Установи Python **3.11 или 3.12** (отметь `Add python.exe to PATH`).
3. Запусти **`01_SETUP.bat`** (скачает Pygame-ce из интернета).
4. Запусти **`02_RUN.bat`** — меню игры откроется даже без модели Vosk.
5. Для настоящего распознавания голоса дополнительно запусти **`03_DOWNLOAD_VOICE_MODEL.bat`**. Он установит `vosk`, `sounddevice` и скачает русскую офлайн-модель **≈45 МБ**. Перезапусти игру, нажми **V** и говори в микрофон.

**В PyCharm:** File → Open → папка проекта; настрой Python Interpreter на `.venv\Scripts\python.exe`; запускай `main.py`. Все данные уровней/персонажей доступны как обычные файлы.

## Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки | Ходьба |
| Shift | Бег (враги слышат шум) |
| E / Пробел | Поднять предмет, прочитать записку, выйти из сектора |
| Tab | Панель голосовых команд с кнопками |
| 1–0, -, =, Backspace | Повторить команды панели с клавиатуры |
| V | Включить/выключить **настоящий** микрофон Vosk |
| M | Карта сектора |
| H, B, G | Аптечка, батарея, отвлекающий маяк |
| Esc | Пауза/назад |

**Важное:** игрок движется WASD, а команды Новы запускают специальные действия. Без речевой модели всё можно тестировать с клавиатуры; это **резервный способ ввода**, не AI.

## Как пройти уровни

1. Найди по комнатам **модуль сканирования**, **модуль взлома** и **карту доступа** (на следующих уровнях модули других способностей). Подойди вплотную к предмету и нажми `E`.
2. Найди **главный терминал в левом верхнем секторе**: `Подключение → Сканируй → Взломай → Открой`. Первый шлюз откроется.
3. Пройди через шлюз в **центральную часть** и доберись до энергетического ядра (обычно в верхней комнате). Найди запись, изучи подсказку, выполни: `Сканируй → Отключи нужное ядро → Активируй нужное ядро → Открой`.
4. После этого второй шлюз откроется. Доберись до **выхода в правом нижнем секторе**, нажми `E`.
5. Повтори на трёх уровнях. В конце выбери концовку; лучший сценарий требует найти **модуль памяти**.

**Не знаешь, куда идти?** Нажми `7` или скажи «Нова». Цветовые команды полностью представлены в меню `Tab`.

## Содержание

- `main.py` — точка входа;
- `echo_game/game.py` — Pygame, HUD, отрисовка, меню, экран карты, клавиатура;
- `echo_game/world.py` — столкновения, турели, камеры, дроны, поведение, предметы, задания, адаптивная сложность;
- `echo_game/voice.py` — реальный Vosk, микрофон в отдельном потоке;
- `echo_game/commands.py` — перевод фраз в игровые команды;
- `echo_game/storage.py` — SQLite, сохранения, таблица результатов, достижения и демонстрационный Premium;
- `maps/level_1.tmj` ... `level_3.tmj` — **исходные карты Tiled**, редактируются визуально;
- `assets/source_svg/*.svg` — **редактируемые векторы** всех персонажей, предметов, фонового оформления;
- `assets/sprites/*.png` — игровые PNG, полученные из SVG;
- `assets/tiles/tileset.tsx`, `tileset.png` — тайлсет для редактора Tiled;
- `assets/audio/*.wav` — оригинальные звуки, редактируются в Audacity;
- `story/levels.json` — сюжет, диалоги Новы, логика решений головоломок;
- `assets/ui/theme.json` — цвета, размер окна, звуковой флаг;
- `docs/previews/*.png` — схемы всех трёх карт;
- `scripts/create_content.py` — исходный генератор арта и карт; **не запускай повторно после ручного изменения карт**, иначе перезапишет их;
- `scripts/export_svg.py` — конвертирует отредактированные SVG → PNG, **не трогая карты** (понадобится `cairosvg`);
- `scripts/create_audio.py` — исходный генератор оригинальных эффектов WAV;
- `scripts/export_map_previews.py` — создаёт PNG-превью из изменённых TMJ;
- `tests/test_game.py` — проверки игровой логики без Pygame;
- `docs/EDITING_GUIDE.md` — пошаговая инструкция для изменения карт/героев/сюжета.

## Проверка тестов

Запусти `04_TEST.bat` или `python -m unittest discover -s tests -v`. В среде сборки выполнено 40 тестов игровой логики (успешно). **Запуск графического окна и проверка микрофона на пользовательском Windows-компьютере ещё не выполнены**: в среде сборки нет Pygame и устройства микрофона. Если при первом запуске появится ошибка, приложи `crash_log.txt` или скриншот, и мы исправим.

## Игровые возможности

Три последовательных сектора; большие лабиринтные карты и тупики; модули НОВЫ; аптечки, батареи, маяки, записки; распознавание русских голосовых команд Vosk; камеры с полем зрения и накоплением подозрения; тревога и турели; дроны со схемой патруль → поиск → преследование, оглушение EMP; маскировочный щит; головоломки последовательностей и энергетических контуров; адаптация интенсивности охраны по статистике ошибок/обнаружений; два финала; SQLite, рекорды, достижения; демонстрационный Premium Challenge. Premium — **имитация покупки без денежных платежей**, не интеграция банковского провайдера.

## Происхождение материалов

Векторные изображения, плитки карт, игровые уровни и все WAV созданы специально для этого прототипа программной генерацией. Исходники графики и генераторы звуков в ZIP. Модель Vosk сторонняя (распространяется отдельно с сайта разработчика, не входит в ZIP), запуск требует загрузки. Игровые персонажи/названия/диалоги оригинальные; ни одна готовая игра не скопирована.

## Ограничения первой полной сборки

Карта рисуется ортогонально сверху (не 3D-камера). Маскировка защищает от обнаружения и повреждений, но не делает героя физически невидимым. Адаптивная сложность — алгоритм на правилах, **не вторая нейросеть**. Комплексный сценарий сделан в виде трёх завершённых игровых секторов; прохождение вручную на настоящем ПК нужно проверить дополнительно. Командная история GitHub, работа трёх внешних тестировщиков и финансовые транзакции не создавались и не заявляются.
