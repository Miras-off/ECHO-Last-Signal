# Git history and responsibility log

## Source of commit history

This Git repository was **constructed from genuine previously exported ZIP releases** of ECHO, in the following order:

1. v0.1 prototype
2. v1.0 playable
3. v1.0.4 settings and interface
4. v1.0.5.1 rooms and camera visibility
5. v2.0 AI and puzzles
6. v2.1 visuals and combat
7. v2.1.1 cinematic audio
8. v2.1.2 lives, monetization demo

These are *archive imports*, not the original chronological Git development activity. The import commit dates correspond to the day the repository history was reconstructed. Authors are deliberately recorded as **ECHO Archive Import** to avoid falsely attributing imported code to either student.

## How to document real team contributions

Both teammates should use their own GitHub accounts, edit files they actually worked on, commit changes under their own account and open PRs. Suggested first contributions:

- Participant A: review and improve game tests / launch scripts / README with actual verification output.
- Participant B: adjust Nova dialogue and visuals, update story and gameplay text, write a guide and record actual playtesting results.

If the team members' real work division differs from the suggestions, record the truth instead. The course requires evidence of individual participation; imports alone do not satisfy it.
