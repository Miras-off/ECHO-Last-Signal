# ECHO v2.1.3 — Бесплатное восстановление жизней

## Новая механика

- Игра начинается с тремя жизнями.
- При каждом настоящем поражении списывается 1 жизнь.
- Когда жизней меньше трёх, раз в **15 минут** начисляется **+1 бесплатная жизнь**, максимум до 3 бесплатных жизней.
- Отсчёт начинается после первого поражения и **продолжается при закрытом приложении**: используется локальная отметка времени в SQLite.
- Дополнительные поражения во время отсчёта не сбрасывают его.
- При 0 жизней доступ временно закрыт, но по окончании отсчёта появляется 1 жизнь и игра снова доступна.
- В меню, магазине и на экране блокировки показан таймер формата ММ:СС.
- Платный учебный набор +3 жизни (490 ₸ демо) продолжает работать и может увеличить число жизней выше трёх. Когда запас 3 или больше, бесплатная регенерация останавливается.
- Premium (1 490 ₸ демо) по-прежнему даёт безлимитные жизни и Challenge Sector.
- Никаких настоящих платежей, банковских реквизитов или проверки через сервер нет.

## Как обновить установленную версию

1. Сделайте резервную копию `save_data/echo.sqlite3` из своей игры.
2. Закройте ECHO.
3. Поверх исходников v2.1.2 распакуйте **патч** `ECHO_v2.1.3_FREE_LIFE_PATCH.zip`, сохраняя структуру папок.
4. Запустите `02_RUN.bat`.
5. База данных автоматически получит новый столбец `wallet.regen_started_at`. Прогресс, число жизней, достижения и покупки сохранятся.

**При переходе со старой версии, если до обновления у вас было меньше трёх жизней**, первый 15-минутный отсчёт начинается при первом запуске v2.1.3. Это нужно потому, что предыдущая версия не сохраняла время последней потери жизни.

## Для GitHub

Из своего локального репозитория, после копирования файлов патча:

```powershell
# Лучше вести изменение отдельной веткой
git switch -c feature/free-life-regeneration
git add echo_game/storage.py echo_game/game.py tests/test_life_regeneration.py README.md CHANGELOG_v2.1.md docs/
git commit -m "feat: regenerate one free life every 15 minutes"
git push -u origin feature/free-life-regeneration
```

Затем откройте Pull Request из `feature/free-life-regeneration` в `main`, приложите результаты тестов, после проверки объедините его.

## Проверка

Запустить: `python -m pytest -q` или `04_TEST.bat`.

Дополнительно проверить на Windows:

1. Потерять жизнь и увидеть таймер.
2. Закрыть ECHO; по истечении 15 минут заново открыть и увидеть восстановленную жизнь.
3. При 0 жизней дождаться +1 и войти в игру.
4. Проверить, что после трёх жизней дополнительные бесплатные жизни не начисляются.
5. Проверить, что демо-покупка +3 жизни и Premium по-прежнему работают.

### Ограничение офлайн-таймера

Отсчёт использует системные часы ПК. Для учебного прототипа это достаточно, но в настоящем коммерческом продукте для защиты от перевода часов использовали бы серверное время. Не нужно менять системное время для демонстрации, это может затронуть другие приложения.
