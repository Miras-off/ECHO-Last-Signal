# Как самостоятельно редактировать ECHO (без навыков Python)

## 1. Персонажи — Inkscape (бесплатно)

Открой `assets/source_svg/alex_idle.svg` в **Inkscape**. Это настоящий векторный файл: можно выделять, перекрашивать и перемещать шлем, тело и другие части как элементы изображения. Сохрани его с тем же именем. Персонаж имеет ещё три позы: `alex_walk.svg`, `alex_hurt.svg`, `alex_victory.svg`.

Векторные PNG, которые загружает игра, находятся отдельно в `assets/sprites/*.png`. После изменения SVG **обязательно обнови PNG**: в Inkscape выбери «Файл → Экспорт» в тот же `.png`, либо установи зависимость `pip install -r requirements-editing.txt` и запусти `python scripts/export_svg.py`.

Робот-компаньон: `nova.svg`; охрана: `drone.svg`, `camera.svg`, `turret.svg`; объекты: `terminal.svg`, `core.svg`, `gate.svg`, `exit.svg`, `medkit.svg`, `battery.svg`, `module.svg`, `note.svg`, `lure.svg`, `keycard.svg`.

**Не меняй имена PNG:** игровой код ищет их по названию. Сохраняй прозрачный фон и примерно тот же размер/пропорции.

## 2. Карты — Tiled Map Editor (бесплатно)

1. Установи **Tiled Map Editor**.
2. File → Open → `maps/level_1.tmj`. Это **исходная редактируемая карта**, а не PNG-картинка.
3. Панель слоёв: `Пол и стены` — изменяй плитки кистью. `Объекты — меняйте позиции мышкой` — можно выделить и перетащить предмет, камеру, дрон, терминал или выход.
4. Сохрани `Ctrl+S`. Игровой код при следующем запуске читает обновлённый `.tmj`.
5. В папке `docs/previews/` уже лежат готовые схемы. После изменения карты можешь пересоздать превью командой `05_MAP_PREVIEWS.bat` (нужна Pillow).

**Как устроены тайлы:** свободный пол (индексы 1,3,4,6,7,8); непроходимые стены (2,5). **Шлюзы** — объекты типа `gate`, изначально закрыты. Ключи `gate_id=A` и `gate_id=B` управляют открытием соответствующих ворот. На каждой карте их два. Дрону задаются `target_x`, `target_y`; камере `angle`, `range`, `sweep`.

**Важные ограничения редактирования:** не удаляй и не переименовывай объекты типов `spawn`, `main_terminal`, `core`, `exit` и не меняй `gate_id`, если не меняешь код. Не закрывай единственные проходы стенами. После изменения запусти `04_TEST.bat`: он проверит, что все ключевые объекты достижимы. Уровни ориентированы на тайл 48×48.

## 3. Диалоги / сюжет / загадки

Открой `story/levels.json` в любом текстовом редакторе (VS Code или блокнот). Строки `dialog` и `clue` игра действительно **читает из файла при запуске**. `core_off` и `core_on` — правильная пара действий для энергетического ядра: `red`, `yellow`, `blue`. Если поменяешь подсказку, соответствующим образом измени пару в JSON, иначе она не совпадёт с ответом. `name` определяет надпись сектора в HUD.

Для изменения отдельных записок открой карту в Tiled, выдели объект `note` и отредактируй пользовательское свойство `text`.

## 4. Цвета и интерфейс

`assets/ui/theme.json`: `palette.accent`, `palette.panel`, `palette.background`, `palette.text`, `palette.bad` и т. д. Цвета в формате `#RRGGBB`. Сохрани JSON, перезапусти игру.

Файлы оформления `assets/source_svg/logo.svg` и `cover.svg` можно редактировать в Inkscape, а потом экспортировать в соответствующие PNG в `assets/ui`.

Расположение кнопок, HUD, меню и окон задано в `echo_game/game.py`; для переноса элементов нужно менять координаты в коде. SVG-текст не «редактирует» верстку Pygame автоматически — это разные элементы проекта.

## 5. Звуки — Audacity

`assets/audio/*.wav` — полноценные редактируемые аудиофайлы, открываются в бесплатном Audacity. Можно обрезать, изменить громкость, высоту тона, наложить реверберацию и заменить звуки, не меняя их названий. `scripts/create_audio.py` — исходный Python-генератор всех звуков. **Не запускай его после ручного редактирования WAV**, иначе перезапишет изменения.

## 6. Работа вдвоём через GitHub Desktop

Каждый устанавливает GitHub Desktop, клонирует один приватный репозиторий и создаёт свою ветку. Дизайнер меняет `.tmj`, `.svg`, `.png`, `.wav`, `.json`; разработчик меняет файлы в `echo_game/`. После сохранения и проверки — Commit и Push, затем Pull Request. Коммиты должны отражать реальные изменения соответствующего участника.
