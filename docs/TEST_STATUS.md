# Состояние тестирования ECHO 1.0

Дата сборки: 21 октября 2026 г.

## Что действительно проверено

- `python -m py_compile` — модули Pygame (синтаксис), механики и JSON-редактор успешно разобраны Python.
- 38 автотестов `unittest`, запуск в среде сборки: **PASS 40/40**.
- Проверка существования ключевых объектов и достижимости обязательных предметов.
- Проверка недоступности ядра за воротами, доступности после открытия.
- Проверка успешного прохождения трёх этапов логики: все предметы → терминал → ядро → выход.
- Проверка рукописного распознавания интентов текста, логики щита и импульса.
- SQLite: сохранение, результаты, демонстрационная разблокировка контента.

## Что ещё требует проверки на пользовательском Windows-ПК

- Реальный запуск Pygame в графическом окне, поддержка оборудования и частота кадров (в среде сборки Pygame не установлен).
- Распознавание голоса Vosk на **настоящем** микрофоне (модель загружается отдельно).
- Проверка каждого прохождения вручную, баланс охраны, удобство UI.
- Проверка конкретной версии карт после ручного редактирования в Tiled.
- Юзабилити-тестирование на минимум трёх участниках не из команды.

Важно: автоматические тесты — **не замена** ручных тестов или реальных пользовательских отчётов. Никаких несуществующих внешних тестировщиков и обнаруженных реальных ошибок здесь не заявляется.
