# ECHO 2.0 — статус проверок релиз-кандидата

В контейнере проверено: **50 unit tests, 145 subtests passed** (`python -m pytest -q`). Код Python успешно скомпилирован `compileall`; JSON карт, девять головоломок и SVG проверены отдельными тестами. Контент карт связан с World и редактируемыми `.tmj`.

Тестируются: 3 уровня, маршруты и шлюзы, корректность схем, 9 терминалов, ошибки и награды, сохранение состояния/заметок, Q-learning и сохранение Q-таблицы, базовая игровая логика, команды, дроны, коллизии и разделение комнат.

Не следует выдавать эти проверки за выполненные.

Для проверки на Windows: `01_SETUP.bat` → `02_RUN.bat`, затем `03_DOWNLOAD_VOICE_MODEL.bat` (официальная русская модель). Если появится `crash_log.txt`, приложите его при сообщении об ошибке.
