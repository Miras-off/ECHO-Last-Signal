# ECHO v2.1.3 — монетизация, жизни и демо-касса

## Модель Freemium

- Каждый профиль получает 3 стартовые попытки. Повторные перезапуски игры не возвращают потерянные жизни.
- Жизнь списывается **только при переходе из игрового режима к экрану смерти**, а не при каждом кадре рендера, открытии меню или перезапуске окна.
- При 0 жизней запуск, продолжение и повтор уровня временно заблокированы. Через 15 минут автоматически вернётся 1 бесплатная жизнь, после чего игру можно продолжить. Premium снимает ограничения по числу попыток.
- Восстановление **+1 жизнь за каждые 15 минут** работает с момента потери первой жизни и продолжает отсчёт при закрытой игре. Бесплатный запас ограничен тремя жизнями. Когда жизней 3 или больше (включая купленные), таймер приостанавливается. Сброс сохранения не добавляет жизни.
- Цены вымышлены и указаны для учебной демонстрации: +3 жизни — 490 ₸; Premium Pass — 1 490 ₸.
- Premium Pass открывает неограниченные попытки и Challenge Sector. Легаси-разблокировка Challenge Sector из предыдущей версии сохраняется, но сама по себе не делает попытки бесконечными.

## Экраны

1. **Главное меню:** показывает остаток жизней, «Новая игра» перенаправляет на блокировку при нуле.
2. **Экран поражения:** списывает ровно одну жизнь, показывает остаток. При нуле кнопка повторного запуска заменяется на «Купить жизни».
3. **Экран блокировки:** показывает обратный отсчёт бесплатной жизни, предлагает демо-покупки и возвращает в меню после восстановления.
4. **Магазин:** обратный отсчёт до бесплатной жизни, обе демо-покупки, остаток попыток и доступ к Premium Challenge.
5. **ECHO PAY / Демокасса:** название заказа, цена, назначение, формат оплаты «TEST MODE», подтверждение без реальной платёжной формы.
6. **Чек:** локальный номер заказа и подтверждение; возвращает игрока на результат или в магазин.

## База данных

`echo_game/storage.py` и локальная `save_data/echo.sqlite3`:

- `wallet`: `lives`, `unlimited`, `defeats`, `regen_started_at` — число попыток, Premium и временная отметка начала восстановления, `CHECK(lives >= 0)`.
- `demo_purchases`: `receipt`, `product`, `price_kzt`, `purchased_at` — журнал фиктивных заказов.
- `unlocks`: Premium Challenge и достижения (сохранена совместимость со старыми базами).
- `saves`: игровой прогресс. Очистка `saves` **не** изменяет `wallet`.

**Безопасность:** никаких настоящих платежей, номеров карт, сроков действия, CVV, логинов банков, сетевых запросов и сбора персональных платёжных данных. Подтверждение — учебное моделирование заказа.

## Как показать преподавателю

1. Покажи три жизни в меню.
2. Проиграй один раз: станет две жизни, появится таймер 15:00.
3. Перезагрузи игру: счётчик продолжит идти с прежнего момента.
4. Проиграй ещё дважды: 0 жизней и временная блокировка.
5. Дождись 15 минут от первого поражения: автоматически появится 1 жизнь, доступ восстановится.
6. Открой магазин, покажи демо-набор «+3 жизни», итог 490 ₸ и отсутствие реальных платежей.
7. Нажми «Подтвердить демо-оплату», посмотри чек; отдельно покажи Premium Pass и Challenge Sector.

**Примечание для защиты:** ожидание на таймере можно показать на заранее подготовленном отдельном тестовом профиле; проверять его нужно по реальным часам (или детерминированным unit tests), без изменения времени на компьютере преподавателя.

Проверяй покупки только в рамках прототипа: платёжного провайдера здесь нет и быть не должно для демонстрации.
