## Нефункциональные требования
- NFR-01: офлайн-прохождение после установки модели Vosk.
- NFR-02: 60 FPS — целевой показатель; производительность требует измерений на целевом ноутбуке.
- NFR-03: без краша при отсутствии микрофона; резервный ввод для диагностики.
- NFR-04: данные сохраняются локально, история не отправляется в сеть.
- NFR-05: доступный контраст, русскоязычный интерфейс, понятные статусы дронов.
- NFR-06: кроссплатформенный Python-код; основная целевая ОС Windows 11.

## User Stories / Acceptance Criteria
1. Как игрок, хочу начать новую игру: Start открывает первый уровень, сохранённый слот сбрасывается.
2. Как игрок, хочу использовать голос: включение V при установленной модели меняет статус на «СЛУШАЕТ», произнесённая команда вызывает игровое действие.
3. Как игрок, хочу обходить камеры: игрок за стеной не обнаруживается, пересечение видимой области повышает подозрение.
4. Как игрок, хочу улучшать Нову: найденный модуль открывает способность, отсутствие модуля блокирует действие.
5. Как игрок, хочу решать головоломки: ответ выбирается мышью/1–3, неправильный ответ повышает тревогу, правильный сохраняется.
6. Как игрок, хочу видеть назначение ядер: при приближении HUD показывает назначение и нужные действия, N хранит инженерную схему.
7. Как игрок, хочу возобновить игру: после паузы/перехода сохранённые задачи и найденные модули остаются.
8. Как игрок, хочу освоить игру: инструкция и легенда управления доступны из меню.

## MoSCoW
**Must**: FR01–FR10, FR12. **Should**: FR11/FR13/FR14. **Could**: озвучка Новы, новые скины. **Won't в текущей версии**: реальные платежи, сетевой кооператив.

## UI/UX-переходы (реализованы в Pygame)
Start → Menu → Game → Pause/Settings → Game → Results → Next Level/Final; Menu → Help/Records/Store; Game → Notes/Map/Commands/Puzzle. Отдельный Figma-прототип не включён; кликабельность демонстрируется работающими экранами игры.
