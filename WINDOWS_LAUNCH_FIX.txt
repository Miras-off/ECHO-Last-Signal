ECHO WINDOWS START FIX v1.0.1

The launcher BAT scripts were fixed for Windows CMD.
All .bat files now use CRLF line endings and ASCII-only command text.

1. Extract the ZIP into a normal folder.
2. Run 01_SETUP.bat once (Python 3.11 or 3.12 recommended).
3. Run 02_RUN.bat.
4. Optional: run 03_DOWNLOAD_VOICE_MODEL.bat for real microphone commands.

Manual launch (from the extracted folder):
.venv\Scripts\python.exe main.py

If an error remains, copy the full console error or crash_log.txt.
