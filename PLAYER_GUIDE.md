# ECHO: Последний сигнал
## Руководство пользователя

**Версия игры:** 2.1.2  
**Жанр:** 2D Sci-Fi Stealth / AI Voice Quest  
**Платформа:** Windows  
**Язык:** русский

---

## 1. Описание игры

**ECHO: Последний сигнал** — научно-фантастическая двухмерная игра с видом сверху, объединяющая исследование помещений, скрытное прохождение, логические головоломки и голосовое управление.

Главный герой Алекс просыпается на заброшенном исследовательском корабле «Атлас-9», практически ничего не помня о произошедшем.

Его единственная напарница — Нова, виртуальный AI-помощник, который помогает исследовать корабль, взламывать системы безопасности и управлять оборудованием.

Кораблём управляет враждебная система ЦЕРБЕР, использующая камеры наблюдения, дронов и турели.

**Главная цель:** восстановить системы корабля, раскрыть обстоятельства произошедшего и добраться до спасательной шлюпки «Аврора».

## 2. Игровые уровни

### Уровень 1 — «Пробуждение»

Медицинский сектор корабля.

Игрок знакомится с управлением, ищет первые модули Новы, карту доступа и решает головоломки медицинского отсека.

Основная задача — восстановить доступ к шлюзам и покинуть медицинский сектор.

### Уровень 2 — «Мёртвый сектор»

Лаборатории и инженерные помещения.

Игрок сталкивается с более опасными системами безопасности, использует маскировку и электромагнитный импульс, решает задачи электропитания и получает новые сведения о корабле.

Основная задача — восстановить необходимые системы и добраться до командного центра.

### Уровень 3 — «Последний сигнал»

Командный сектор корабля.

Игрок восстанавливает фрагменты информации о ЦЕРБЕРЕ, решает заключительные головоломки и пытается открыть доступ к спасательному ангару.

В финале предусмотрен выбор концовки. Дополнительный вариант зависит от получения модуля памяти.

## 3. Управление

| Клавиша | Назначение |
|---|---|
| W, A, S, D / стрелки | Передвижение персонажа |
| Shift | Бег |
| E / Пробел | Взаимодействие с объектами |
| 1–3 | Выбор ответа в логической головоломке |
| Tab | Открыть список команд Новы |
| V | Включить или отключить распознавание голоса |
| N | Открыть заметки и инженерные схемы |
| M | Открыть карту |
| H | Использовать аптечку |
| B | Использовать батарею |
| G | Использовать отвлекающий маяк |
| Esc | Пауза / возвращение назад |
| F11 | Переключение полноэкранного режима |

Команды Новы можно также выполнять с помощью клавиатуры. Соответствующие клавиши отображаются в меню **Tab**.

## 4. Голосовое управление

Для распознавания русской речи используется локальная модель **Vosk**.

Перед использованием необходимо установить языковую модель и включить микрофон клавишей **V**.

### Основные голосовые команды

| Команда | Действие |
|---|---|
| «Сканируй» | Сканирование объекта или системы |
| «Подключение» | Подключение к терминалу |
| «Взломай» | Взлом защиты |
| «Открой» | Открытие доступного шлюза |
| «Щит» | Временная активация защитного поля |
| «Импульс» | Электромагнитный импульс против дронов |
| «Нова» / «Помощь» | Получение подсказки |
| «Отключи красное» | Отключение красного энергетического контура |
| «Активируй жёлтое» | Включение жёлтого энергетического контура |
| «Отключи синее» | Отключение синего энергетического контура |
| «Активируй красное» | Включение красного энергетического контура |

Также поддерживаются другие команды управления цветными энергетическими контурами.

**Важно:** некоторые команды становятся доступны только после нахождения соответствующего модуля Новы. Команды взаимодействия также могут требовать нахождения рядом с терминалом.

## 5. Логические головоломки

В игре реализовано **9 логических терминалов — по 3 на каждом уровне**.

Типы заданий включают:

- Вычисление кодов доступа.
- Определение правильной последовательности действий.
- Логические условия и поиск противоречий.
- Анализ показаний систем безопасности.
- Управление энергетическими контурами.

### Как решить головоломку

1. Найти устройство с маркером «ЗАГАДКА».
2. Подойти к терминалу.
3. Нажать **E**.
4. Прочитать условие.
5. Выбрать вариант ответа клавишами **1–3** или мышью.

Правильное решение сохраняется в прогрессе и может принести дополнительный предмет.

При неправильном ответе повышается уровень тревоги, но головоломку можно попробовать решить повторно.

Для открытия первого шлюза необходимо решить первые две задачи сектора. Перед завершением уровня требуется решить третью задачу и выполнить действия с энергетическим ядром.

## 6. Энергетические ядра

Каждый уровень содержит головоломку с энергетическими контурами разных цветов.

Чтобы её выполнить, необходимо изучить информацию об устройстве системы и определить, какой контур нужно отключить, а какой активировать.

### Порядок взаимодействия

1. Подойти к энергетическому ядру.
2. Изучить инженерную подсказку.
3. Выполнить команду сканирования.
4. Отключить необходимый цветовой контур.
5. Активировать нужный контур.
6. Открыть шлюз.

Рядом с ядром отображается **контекстная инженерная схема**, которая помогает определить назначение контуров.

Полученные сведения также сохраняются в заметках, доступных по клавише **N**.

## 7. Противники и скрытное прохождение

В ECHO реализованы три основных типа угроз.

### Камеры наблюдения

Контролируют определённую область с помощью красного сектора обзора. Их зона обнаружения учитывает препятствия.

Игроку необходимо обходить камеры, используя стены и безопасные участки.

### Дроны безопасности

Передвигаются по маршрутам, обнаруживают игрока и могут переходить от патрулирования к поиску и преследованию.

Для противодействия можно использовать укрытия, отвлекающий маяк и способности Новы.

### Турели

Стационарные охранные устройства, способные обнаруживать и атаковать игрока.

Рекомендуется избегать прямой видимости и использовать доступные защитные способности.

## 8. Нова и её способности

По мере прохождения игрок собирает специальные модули, расширяющие возможности AI-помощницы.

| Модуль | Назначение |
|---|---|
| Сканирование | Анализ объектов и терминалов |
| Взлом | Работа с защищёнными системами |
| Щит | Временная защита персонажа |
| Импульс | Оглушение ближайших дронов |
| Управление | Дополнительный контроль систем корабля |
| Память | Восстановление информации и доступ к дополнительной концовке |

Некоторые способности расходуют энергию Новы. Для её восстановления используются батареи.

## 9. Предметы и инвентарь

**Аптечка** — восстанавливает здоровье Алекса.

**Батарея** — восстанавливает энергию Новы.

**Ключ-карта** — используется для открытия защищённых проходов.

**Отвлекающий маяк** — привлекает внимание охранных дронов.

**Модули** — предоставляют новые способности Новы.

**Записи** — содержат сюжетную информацию и подсказки.

Предметы можно подбирать с помощью клавиши **E**, находясь рядом с ними.

## 10. Система искусственного интеллекта

Игра включает два AI-компонента.

### AI №1 — Vosk

Используется для распознавания голосовых команд. Работает локально после установки русскоязычной модели, без обращения к облачным сервисам.

### AI №2 — Q-learning

Используется для адаптации сложности.

Система анализирует поведение игрока, включая обнаружения, ошибки, полученный урон и состояние здоровья.

По результатам прохождения помещений алгоритм выбирает параметры сложности. Поэтому при успешной игре охрана может становиться опаснее.

Данные обучения сохраняются локально.

## 11. Система жизней и Premium

В ECHO реализована учебная модель монетизации **Freemium**.

При первом запуске игрок получает **3 жизни**.

Каждое поражение отнимает одну жизнь. После трёх поражений повторный запуск блокируется.

### Демонстрационный магазин

| Товар | Цена | Результат |
|---|---|---|
| Набор +3 жизни | 490 ₸ | Восстанавливает три попытки |
| Premium Pass | 1 490 ₸ | Безлимитные жизни и Challenge Sector |

Бесплатное восстановление попыток отсутствует.

После выбора товара открывается экран **ECHO PAY**, на котором пользователь подтверждает учебную покупку.

**Все платежи фиктивные.** Игра не запрашивает данные банковских карт, не подключается к платёжным системам и не списывает настоящие деньги.

После подтверждения создаётся демонстрационный чек, а приобретённые возможности сохраняются.

## 12. Сохранение прогресса

В игре предусмотрено локальное сохранение состояния прохождения.

Сохраняются игровые данные, включая прогресс, предметы и выполненные задания.

Система использует SQLite для сохранений, статистики, количества жизней и демонстрационных покупок.

После перезапуска игры потерянные жизни автоматически не восстанавливаются.

## 13. Музыкальное сопровождение

Игра содержит различные звуковые эффекты и динамическую фоновую музыку.

Звуки сопровождают обнаружение камерами, преследование дронами, стрельбу турелей, использование способностей Новы, работу терминалов и открытие шлюзов.

В настройках можно регулировать громкость музыки, эффектов и сигналов Новы.

## 14. Установка и запуск на Windows

**Минимальные программные условия:** Windows, Python 3.11 или 3.12 и необходимые Python-библиотеки.

### Порядок установки

1. Скачать или клонировать проект ECHO.
2. Открыть папку проекта.
3. Запустить `01_SETUP.bat` для установки зависимостей.
4. Для голосового управления запустить `03_DOWNLOAD_VOICE_MODEL.bat`.
5. Запустить игру через `02_RUN.bat`.

Для установки Python-библиотек и скачивания голосовой модели потребуется интернет. После установки модель распознавания речи может работать офлайн.

При ошибке запуска следует проверить консоль и файл `crash_log.txt`.

## 15. Советы по прохождению

- Исследуйте помещения и собирайте модули Новы.
- Перед использованием терминала убедитесь, что персонаж стоит достаточно близко.
- Следите за шкалой тревоги и здоровьем.
- Используйте заметки **N**, если забыли подсказку.
- Не расходуйте энергию Новы без необходимости.
- Изучайте маршруты дронов и области обзора камер.
- Сохраняйте аптечки для опасных участков.
- Помните, что каждое поражение уменьшает количество доступных попыток.
